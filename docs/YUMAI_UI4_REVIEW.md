# 语脉 YUMAI UI 4.0 — 阅读优先设计与验收

## 设计目标

以 Chrome 弹出窗口和网页内浮窗为核心，不再让紫色渐变、层层卡片和数十个 9–11px 标签争夺注意力。

### 用户体验原则
- 品牌栏只回答“这是什么软件”“当前选择了哪家服务商”“去哪看历史和设置”，不假装 API 已连接。
- 工具条在 440–560px 宽度保持单行，按钮最小点击面积约 32–36px，避免文字溢出。
- 原文 / 译文相邻且层级清楚；原文字体改为平台 sans-serif，防止网页浮窗因为缺少 Tailwind preflight 而回退成大号等宽字体。
- 译文区域能够独立滚动；保留此前可拖动的上下和左右分栏比例。
- 词汇含义仍是词典视图的主要信息；搭配、近义词、例句按需展开。
- 空态、错误态、流式生成态、复制和朗读状态的原有逻辑不变。
- 尊重 prefers-reduced-motion；有明显 focus-visible 键盘焦点。
- 不改模型请求、存储键、历史格式、TTS 设置和扩展消息约定。

## 主要变更
- Header: 语脉/YUMAI 标志与 36px 工具按钮、简洁 API 服务商选择。
- TranslatorMain: 紧凑单行语言工具栏、原文标题、内容导向的结果字体、清晰的操作区。
- WordContextCard: 统一字重、间距与点击热区。
- App/ index.css/ content.css: 中性的视觉底色和作用域限定的 UI 4.0 样式；Web 与 Shadow DOM 共用。
- content.css: 网页内浮窗改为 460×590，确保选择窗口仍受视口约束。
