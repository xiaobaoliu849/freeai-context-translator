# 语脉 YUMAI · Intelligent UI 体验升级路线图

## 产品定位
**读懂文字，更懂语境。** 不以花哨动效冒充 AI 智能，而是让用户在阅读和翻译时自然获得最相关的信息。此处的 Intelligent UI 是设计目标，并不代表已集成某个专有框架。

## P0：品牌及兼容（本次 PR）
- 语脉 / YUMAI 的网页标题、扩展名称、头部、浮动翻译卡片、右键菜单统一
- 引入轻量 SVG 品牌标识；后续须输出同形状 16/48/128 PNG 图标覆盖现有扩展图标
- 服务商尚未验证时不使用误导性绿色“已连接”动态圆点
- 将浮动窗口的拖动热区约束在品牌区域，减少与右侧按钮事件冲突
- 给关键图标按钮增补中文 aria-label
- 尊重系统 prefers-reduced-motion
- 保留仓库名、历史记录/API Key 存储键、右键菜单 ID、快捷键、现有翻译逻辑

## P1：可靠性（下一轮）
1. 复制成功后才显示对勾；失败显示可操作提示；避免 Promise rejection 后误报。
2. 补充连接状态：未测试、测试中、连接成功、连接失败；不能仅凭配置了提供商就显示已连接。
3. 浮窗打开与关闭时处理键盘焦点；Esc 关闭词典并返回整句翻译，关闭时焦点归位。
4. 验证弹窗在窄屏、浏览器缩放与长网页滚动下的位置和滚动行为。

## P2：简化信息架构
- 初次配置分为“选择服务商 → 输入 API Key → 测试连接”；高级模型 ID、Base URL 折叠。
- 译文为主，辅助信息为次；词典默认显示词、发音、词性、语境释义，搭配和例句按需展开。
- Web 宽屏保留双栏和拖动；Chrome popup 采用紧凑的上下布局。
- 减少渐变、阴影、8–10px 超小字；正文以 14–16px 为主，点击区域目标 ≥32px。
- 增加暗色主题、字体缩放和键盘操作提示。

## P3：语境驱动的 Intelligent UI
- 选择单词显示语境词典；短句显示翻译；长文显示翻译和按需展开的术语分析。
- 用户始终可以手动切换模式，不让自动识别锁死操作。
- 加入可选的词汇收藏、个人学习记录与上下文连续跟进。
- 流式、错误、重试、取消均用清晰文本反馈，不依赖动画或色彩判断。

## 发布门槛
- npm run lint、npm run build、npm run build:ext 均通过（本 PR 尚未执行，本地/CI 待验）。
- Chrome 真实测试：划词、快捷键、弹窗关闭与固定、朗读、历史、切换模型、API Key 设置。
- 新旧版本升级后本地设置和历史不丢失。
- 16px 扩展图标清晰，兼顾明暗浏览器工具栏背景。
- 不直接推送 main；所有变更先经 PR 检查。
